# Object-Oriented Programming in Java

A comprehensive collection of Java programs demonstrating core Object-Oriented Programming (OOP) concepts. This repository contains practice implementations, examples, and exercises developed to strengthen understanding of OOP principles in Java.
## Concepts Covered
 ### Encapsulation

Using classes to bundle data and methods together while controlling access.

 ### Inheritance

Reusing properties and behaviors from parent classes.

 ### Polymorphism

Implementing method overriding and dynamic behavior.

 ### Abstraction

Using interfaces and abstract classes to hide implementation details.

 ### Method Chaining

Designing methods that return objects to allow chained calls.
